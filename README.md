# Smart Meal Planner using LLM

An AI web app that generates personalized meal plans, nutritional insights, and recipe
suggestions in real time.

## What it does
- Uses Hugging Face Transformers to power conversational, LLM-driven recommendations
- Integrates user dietary goals, preferences, and available ingredients into the
  generation prompt
- Returns structured meal plans and recipes through a web interface

## Stack
Python · Hugging Face Transformers · LLMs
